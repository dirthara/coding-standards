# CS-0: Dirthara Coding Standards

These coding standards comprise a set of standard elements that are required to ensure an easy way to collaborate with
multiple developers on the Dirthara project. The goal is to reduce time needed to understand and merge code changes from
different authors and keep a consistent code base.

Every contributor working on this project is expected to have read and understood these coding standards.

Where possible, automated tools should be used to enforce these standards. For instance, PHPUnit can be used to
calculate code coverage, and can in combination with a CI pipeline be enforced. Similarly, a code style package like
Mago can be used to automatically enforce code style. However, developers should not rely on these automated
tools. Every developer is responsible for the quality of their own code.
